1. In-Band: Auth Bypass

Uses quotes and comment syntax (--, #) to truncate the password verification condition.

2. In-Band: UNION-Based

Uses the SQL UNION operator to combine results from original query with unauthorized secret tables (employees, passwords).

3. Error-Based

Forces intentional SQL syntax or type conversion errors to coerce database error messages into printing table names or version strings.

4. Inferential: Blind SQLi

No data printed directly on screen. Attacker sends True/False logical queries and infers data character-by-character based on whether login succeeds or fails.
